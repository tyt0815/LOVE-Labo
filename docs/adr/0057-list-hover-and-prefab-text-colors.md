# 0057. 연속 목록 행과 Prefab 소속 글자색

- 상태: 승인·구현
- 대체: [0053](0053-prefab-source-membership-lines.md)의 Prefab 전용 범위선 표시. 소속 판정은 유지한다.
- 관련: [0051](0051-inline-names-and-prefab-membership.md)의 생성 메뉴 명칭을 New Object로 통일한다.

## 배경과 제약

행 사이 여백과 Prefab 전용 굵은 선이 계층을 읽기 어렵게 했다. 사용자는 일반 트리의 연속 수직선과 회색 호버·선택 배경, 파란 선택 외곽선을 요청했다. 일반 부모·자식 관계와 원본 소속은 분리해야 한다.

## 대안과 판단 기준

전용 범위선과 배경색 대신 글자색을 사용한다. 선택 배경과 충돌하지 않고 일반 계층선과 소속 표시의 의미를 분리할 수 있다. 색만으로 에셋을 식별할 수 없으므로 루트 아이콘과 원본 찾기는 유지한다.

## 결정과 근거

트리와 목록의 행, 에셋 셀 배경은 빈틈 없이 이어진다. 모든 자손에 얇은 수직선을 표시하고 가로 연결선은 생략한다. 공통 Ui.METRICS에서 행 높이와 선 두께를 조절한다.

선택된 행과 조상의 계층선은 해당 가지의 전체 구간에서 강조한다. 다중 선택은 경로들의 합집합을 표시하고 다른 가지의 하위 선은 기본 상태를 유지한다. 강조 색은 테마의 treeLineHighlight, 두께는 Ui.METRICS.treeLineHighlightWidth로 설정한다. 원본 소속 글자색과 선택 경로 선색은 독립적이다.

독립 루트 묶음에는 현재 트리 순서대로 RGBYCM 색을 배정한다. 같은 원본의 별도 배치도 독립 묶음이면 별도 색이다. 한 루트 묶음 안에서는 원본별로 색을 공유하고 새 원본에는 다음 색을 배정한다. 이동·디태치·정렬 후 그리기에서 매번 다시 계산한다. 일반 오브젝트는 기본색이다. 색은 화면상의 보조 표식이며 저장하지 않는다. 원본 없는 Inspector 루트와 직접 작성한 빈 자손의 제외 기준은 유지한다.

공통 호버 판정은 팝업 뒤의 위젯을 제외한다. 불가능한 컨텍스트 메뉴 항목은 숨기고 빈 메뉴는 열지 않는다. New Object는 대상 행에 자손을 추가하며 레벨 계층의 빈 곳에서는 독립 오브젝트를 생성한다.

## 결과

- 긍정: 선택·호버·일반 계층·Prefab 소속의 표시를 분리한다.
- 부정: 여섯 색이 반복되며 색각 차이가 있어 글자색만으로 고유 에셋을 식별할 수 없다.
- 중립: 저장 형식과 런타임 계층은 변경하지 않는다. 표시 색은 접기 상태와 계층 배치에 따라 재계산한다.
