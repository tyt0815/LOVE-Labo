# 0043. 목록 스크롤바를 공유하고 Inspector 계층 높이를 독립 조절한다

- 상태: 채택·구현
- 날짜: 2026-10-09
- 관련: [ADR 0042](0042-hierarchy-prefab-definitions.md)

## 배경과 제약

행 휠 스크롤만으로는 목록의 범위와 현재 위치를 알기 어렵다. 두 Inspector 계층이 화면을 과도하게 차지하지 않으면서 필요할 때 더 많은 노드를 표시해야 한다. 기존 포인터 캡처·Undo·취소 처리와 충돌해서는 안 된다.

## 대안과 판단 기준

- 각 목록에 스크롤바를 별도로 구현하면 thumb 크기·클램프·캡처 규칙이 달라진다.
- 모든 목록을 픽셀 기반으로 바꾸는 것은 불필요하게 행 선택 계약을 바꾼다. 컨트롤은 단위에 독립적으로 만들고 각 소유자가 행 또는 픽셀을 선택한다.
- 계층 자동 높이는 선택 때마다 Inspector 배치를 움직인다. 작은 기본 높이와 명시적인 하단 크기 조절을 사용한다.

## 결정 및 근거

1. 공용 `Scrollbar`가 overflow에서만 트랙·thumb를 표시한다. 트랙 클릭, thumb 드래그, 캡처 해제·취소를 지원한다. 행 기반 소유자는 정수 인덱스로 정규화하고 Inspector는 픽셀 오프셋을 사용한다.
2. Hierarchy, Asset Browser 폴더·파일 목록, Inspector, 내부 오브젝트·컴포넌트 트리, 클래스·폴더 선택 트리, 선택 목록 다이얼로그와 드롭다운에 적용한다. 바를 조작해도 목록 선택이나 에셋·오브젝트 드래그를 시작하지 않는다.
3. 두 Inspector 계층은 각각 3행(78px)을 기본·최소 높이로 사용한다. 하단 손잡이를 드래그해 독립적으로 늘리며 패널 높이에 맞춰 상한을 제한한다. 새 문서를 열면 기본 높이로 시작한다. 높이는 에셋에 저장하지 않는다.
4. 팝업도 포인터 캡처를 지원하며 팝업 닫기, Undo, 포커스 상실에서 진행 중인 스크롤·크기 조절을 종료한다.
5. 2026-10-10 보완: Inspector 제목과 Save 버튼은 고정하고, 그 아래 요약·오브젝트 계층·Parent Class·프로퍼티·컴포넌트 계층 전체를 외부 스크롤 범위에 포함한다. 두 내부 계층은 독립적으로 스크롤한다. 휠 방향으로 내부 계층의 위치가 실제로 바뀌면 해당 계층이 입력을 소비하고, 모두 보이거나 이미 해당 방향의 끝이면 Inspector 전체 스크롤로 전달한다. 계층 위에서 휠을 사용할 때 외부 내용을 탐색할 수 없게 되는 문제를 방지한다.

## 예상 결과

- 긍정: 목록의 위치와 범위가 드러나고 긴 목록을 직접 탐색한다. 작은 Inspector에서도 계층과 프로퍼티를 함께 볼 수 있다.
- 부정: 스크롤바 폭만큼 내용 폭이 줄고 작은 트리에서는 자체 스크롤과 Inspector 전체 스크롤을 구분해야 한다.
- 중립: overflow가 없는 목록에는 바가 나타나지 않는다. 계층 높이는 편집 세션 UI 상태이며 데이터 변경·Undo 대상이 아니다.
