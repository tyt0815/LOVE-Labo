# 0024. 접기 가능한 Details 그룹과 좌우 프로퍼티 열

- 상태: 채택
- 날짜: 2026-10-09
- 부분 대체: [ADR 0023](0023-text-edit-and-component-group-layout.md)의 고정 Transform·평면 오브젝트 프로퍼티 목록
- 확장: [ADR 0012](0012-lua-classes-properties-and-unsaved-levels.md)의 클래스 표시 이름

## 배경과 제약

사용자는 제공한 UE Details 화면처럼 Transform·컴포넌트·클래스 이름의 접기 그룹과 이름/값 좌우 반폭 행을 요청했다. 기본값은 컴포넌트만 접고 나머지는 펼침이다. 초기값 복원은 Refresh처럼 기본 배경 없는 아이콘으로 표시한다. 기존 편집·IME·객체 및 이미지 참조·저장 계약과 사용자가 변경한 Inspector 폭을 유지한다.

## 대안과 판단 기준

- Transform과 선언 프로퍼티의 행 계산을 각각 유지하면 반폭 정렬·복원 아이콘 여백이 달라진다. 공통 PropertyLayout에서 열 위치와 그룹 배경을 계산한다.
- 런타임 클래스에 표시용 필드를 추가하면 사용자 코드와 충돌할 수 있다. LuaClass 로더는 클래스 테이블을 키로 하는 약한 참조 맵에 모듈 이름을 저장하고 Inspector의 합성 클래스에는 표시 이름만 전달한다.
- 모든 그룹을 처음부터 접으면 위치와 오브젝트 값 편집에 클릭이 추가된다. 사용자 요청대로 Transform·클래스는 펼치고 컴포넌트만 접는다.
- 기존 편집 API와 저장 스키마를 통합 UI 때문에 바꾸지 않는다. Inspector는 Transform 편집, ClassInspector는 선언 프로퍼티·참조·override 편집을 유지한다.

## 결정 및 근거

1. `editor/ui/property_layout.lua`는 프로퍼티 행의 이름/값/복원 영역과 접기 그룹 배경·헤더 표시를 공유한다. Inspector와 ClassInspector가 의존하며 이 모듈은 편집 값이나 펼침 상태를 소유하지 않는다. 행은 32px, 값 입력·버튼은 26px이고 값 열은 패널 중앙에서 시작한다.
2. Inspector는 Transform 그룹 상태를 소유한다. 그룹을 접으면 아래 ClassInspector 시작 위치를 즉시 다시 배치한다. 각 Transform 값의 복원은 위치·회전 0, 스케일 1이며 기존 유한수·양수 스케일·각도 정규화 검증을 유지한다.
3. ClassInspector는 컴포넌트별 그룹 뒤에 실제 모듈 이름의 클래스 그룹을 배치한다. 상속받은 프로퍼티도 최종 클래스 그룹 안에 표시한다. 선언이 없는 내장 클래스는 Level/LObject로 표시한다. 클래스 속성이 비어 있는 그룹도 표시하되 불필요한 본문 여백은 두지 않는다.
4. 컴포넌트 그룹은 기본 접힘, Transform과 클래스 그룹은 기본 펼침이다. 펼침 상태는 transient UI 상태이며 JSON에 저장하지 않는다. 접기 직전에 편집 중인 값과 IME 조합을 확정하며 숨긴 행은 클릭 판정에서 제외한다.
5. 모든 선언 타입(number/string/boolean/object/image)은 같은 오른쪽 열을 사용하고 타입 정보는 툴팁으로 제공한다. 초기값 복원은 평소 배경 없는 벡터 화살표이고 호버/누름에 공통 버튼 상태 색을 사용한다. 같은 방식의 Transform 복원도 제공한다.
6. Parent Class 선택 행도 이름/값의 반폭 정렬로 표시하되 문서 연결을 위한 별도 설정 행으로 유지한다. 대상 이름·종류와 에셋 요약 표시는 기존 책임을 유지한다.

## 예상 결과

- 긍정: 작은 행으로 더 많은 값을 표시하고 각 그룹과 필드의 역할이 명확하다. Transform과 클래스 값의 입력 열·복원 동작이 일관된다.
- 부정: 기존 좌표 기반 UI 테스트와 수동 클릭 위치가 바뀐다. 좁은 Inspector에서는 긴 변수 이름·참조 라벨이 축약되고 입력칸은 커서 기반 가로 스크롤을 사용한다.
- 중립: Core·컴포넌트 상속·레벨/Prefab 스키마·Runtime 상태는 변경하지 않는다. 검색·카테고리 필터·컴포넌트 부착 UI·다중 객체 편집은 포함하지 않는다.
