# 0062. 플러그인 탐색 루트를 Assets와 나란히 표시한다

- 상태: 승인·구현
- 변경: [0058](0058-plugins-and-mounted-assets.md)의 탐색 표시 계층. 마운트·참조·권한 계약은 유지한다.

## 배경과 제약

사용자는 플러그인 폴더가 Assets 안이 아니라 같은 깊이에 표시되기를 원한다. 사용자 플러그인 실제 파일은 이미 프로젝트 Plugins에 있으며 Assets와 나란히 존재한다. 저장된 에셋 ID와 CLI의 경로 참조를 깨뜨리면 안 된다.

## 대안과 판단 기준

모든 내부 경로와 직렬화된 참조를 새 네임스페이스로 이전하는 대안은 기존 문서·CLI·Export의 호환성 위험을 만든다. 현재 요청은 폴더 탐색 표시이므로 UI 루트만 분리하고 저장 계약은 유지한다.

## 결정과 근거

AssetFolders는 에셋 브라우저와 폴더 선택 창의 공용 표시 목록을 만든다. Assets, Labo Plugins, User Plugins는 같은 깊이의 루트이며 Assets의 파일 목록에는 플러그인 그룹을 중복 표시하지 않는다. 플러그인 경로의 breadcrumb도 해당 그룹에서 시작한다. 비활성 플러그인 그룹은 표시하지 않는다.

실제 Plugins/<이름>/Assets와 .labo/PluginCache, 내부 Assets/... 마운트 경로, 에셋 ID, 읽기 전용 권한은 유지한다. 의존성 관리 창에는 테마 input 배경의 별도 목록 패널을 두고 스크롤 입력을 해당 목록에 한정한다. 의존성이 없는 항목의 설명은 생략한다.

## 결과

- 긍정: 출처별 루트 구분, Assets 목록 단순화, 기존 참조 호환성.
- 부정: 화면의 루트 경로와 내부 직렬화 경로가 다르며 CLI 안내에서 이를 설명해야 한다.
- 중립: 에셋 파일의 물리적인 이동과 게임 Export 계약 변경은 없다.
