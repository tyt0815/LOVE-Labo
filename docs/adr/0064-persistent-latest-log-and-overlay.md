# 0064. 최신 로그 한 줄과 겹쳐 펼치는 기록 패널

- 상태: 승인·구현
- 변경: [0061](0061-editor-debug-services-and-draw-callback.md)의 최신 로그 5초 표시와 확장 레이아웃.
- 오류 기록 시점 변경: [0065](0065-error-occurrence-logging.md). 아래 표시 프레임마다 기록하는 결정은 오류 발생 시 기록으로 대체한다.

## 배경과 제약

최신 로그가 사라지면 하단바의 내용을 확인할 수 없다. 과거 내역을 펼칠 때 기존 에셋 브라우저와 Inspector의 위치가 바뀌는 것도 사용자의 의도와 다르다.

## 대안과 판단 기준

기존 시간 제한과 작업 영역 축소는 각각 일시 알림과 전용 공간 확보에 유리하지만, 최신 상태 유지와 기존 레이아웃 보존에 맞지 않는다.

## 결정과 근거

접힌 하단바는 흰색 테마 input 배경에 최신 로그 한 줄을 계속 표시한다. 펼친 내역은 고정 하단바 위쪽으로 확장하는 높은 z 순서의 패널이다. 작업 영역은 항상 접힌 하단바의 높이만 제외하므로 기존 패널을 밀지 않는다. 내역 영역에서 클릭·스크롤을 소비해 뒤의 에셋이나 프로퍼티를 조작하지 않게 한다.

고정 하단바 높이는 36px이며 펼치기·접기 버튼과 최신 로그의 위치는 확장 상태에서도 그대로다. 과거 내역만 하단바 위쪽에 표시한다.

상위 패널과 하단바의 중복 여백을 줄여 보이는 간격은 4px로 한다. 기록은 최신 항목을 제외하고 하단에서 위로 쌓으며, 부족한 행은 위쪽을 비운다. 시간순 목록을 위쪽부터 채우는 방식은 적은 기록이 하단 최신 로그와 떨어지므로 채택하지 않는다. 스크롤바는 기존처럼 아래쪽 끝이 가장 최근 기록을 가리킨다.

`log(text, options)`의 선택 항목 `marker`는 기본 `-`인 출력 가능한 Unicode 한 글자다. 별도 위치 인자를 추가하는 대신 기존 옵션 테이블을 사용해 호출 호환성을 유지한다. 고정 폭의 표시 칸을 최신 로그의 화살표 칸과 맞추고 모든 로그 본문을 동일한 X 좌표에 배치한다.

최신 로그와 이전 기록의 간격을 포함해 행 간격은 22px로 통일한다. 동일 내용은 중복 제거하지 않는다. 에디터의 지속 오류도 표시 프레임마다 기록하며 기존 1,000개 보관 한계는 유지한다.

## 결과

- 긍정: 마지막 로그 확인 가능, 레이아웃 유지, 이전 기록 탐색.
- 부정: 펼친 동안 뒤의 콘텐츠가 가려진다.
- 중립: 기록 한계·화면 로그·일시적 도형의 수명은 변경하지 않는다.
