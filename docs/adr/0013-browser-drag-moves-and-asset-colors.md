# 0013. 브라우저 드래그 이동과 에셋 종류별 색상

- 상태: 채택
- 날짜: 2026-10-08
- 확장: [ADR 0011](0011-asset-ids-metadata-and-path-cache.md)의 ID 유지 이동, [ADR 0012](0012-lua-classes-properties-and-unsaved-levels.md)의 Move·Rename
- 글리프 겹침 강조는 [ADR 0015](0015-bundled-editor-font.md)의 동봉 Bold 글꼴로 대체

## 배경과 제약

목록과 폴더 트리 양쪽에서 파일·폴더를 서로 드래그해 옮기고, Lua Class의 종류를 썸네일에서 구분해야 한다. 기존 프로젝트의 원본·메타 동시 이동과 ID 보존을 유지하며 목록 탐색에서 Lua 코드를 실행하지 않는다. 부모 클래스와 프로퍼티 라벨은 더 명확하게 강조한다.

## 대안과 판단 기준

- 드롭 전용 파일시스템 이동을 새로 만들면 메타·현재 문서·복구 처리와 어긋난다. 기존 브라우저 moveEntry와 Project.moveEntry를 공유한다.
- 트리 클릭 즉시 탐색하면 드래그 시작만으로 현재 폴더가 바뀐다. 루트와 펼치기 화살표를 제외한 폴더 탐색은 release까지 미룬다.
- 모든 Lua를 같은 아이콘으로 표시하면 Level·LObject·Component를 구분할 수 없다. 등록된 메타 종류만 읽고 코드 실행 없이 분류한다.
- 종류별 색을 렌더러에 하드코딩하면 사용자 테마에서 바꿀 수 없다. 용도별 테마 역할을 추가하고 Atom One Light 계열 기본값을 둔다.

## 결정 및 근거

1. 목록·트리에서 일반 왼쪽 클릭 후 6픽셀 이상 이동하면 드래그한다. 클릭 동안 포인터를 캡처하고 Esc·팝업 열기·Refresh로 취소한다. 버튼 release에서 목적지를 다시 확인한 뒤 기존 이동 경로를 호출한다.
2. 트리·목록의 폴더와 목록의 빈 공간을 드롭 대상으로 사용한다. 빈 공간은 현재 폴더를 뜻한다. 같은 영역 및 두 영역 사이 양방향을 지원한다. 루트·링크는 드래그하지 않는다. 다른 루트·자기 하위·같은 위치·충돌 대상은 금지하며 최종 쓰기는 Project가 다시 검증한다.
3. 드래그 오버레이는 캡처된 위젯을 통해 Root가 모든 패널 위에 그린다. 목적지 테두리와 이동 안내·불가 사유를 표시한다. 트리 hover 펼치기와 각 영역 가장자리 자동 스크롤을 지원한다.
4. 정사각형 파일 아이콘의 배경은 기본 흰색이다. Level·Prefab·Level Lua·LObject Lua·Component Lua에 assetLevel·assetPrefab·classLevel·classLObject·classComponent 테마 역할을 부여한다. Lua Class는 중앙에 Lv·LO·Cp, 우하단에 작은 Lua 표식을 표시한다.
5. 메타의 scriptKind와 최초 가져오기 헤더에서 component 종류를 인식한다. 이번에는 종류 분류만 제공하고 생성 UI·부착·실행 모델은 추가하지 않는다. Component는 Level·Prefab의 부모 목록에 들어가지 않는다.
6. 인스펙터 라벨은 공통 UI.label로 강조한다. 시스템 폰트나 외부 글꼴 파일에 의존하지 않고 현재 글리프를 약간 겹쳐 굵기를 보강한다.

## 예상 결과

- 긍정: 메뉴 없이 파일을 옮길 수 있고 종류별 썸네일을 빠르게 구분한다. 이동 중 현재 레벨과 ID 참조를 보존하며 사용자 테마에서도 색을 조절할 수 있다.
- 부정: 트리 폴더 탐색의 입력 시점이 press에서 release로 바뀐다. Component 분류가 있다고 해서 실행 기능이 제공되는 것은 아니다.
- 중립: 단일 항목 이동을 제공하며 여러 항목 선택·복사 드래그는 이번 범위에 없다. 일반 이미지 미리보기와 Level·Prefab 실행 계약은 유지한다.
