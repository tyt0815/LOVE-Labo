# 0054. Prefab 파일과 루트 오브젝트 이름 분리

- 상태: 승인·구현
- 원본 연결이 있는 루트의 교체 금지는 [ADR 0055](0055-prefab-container-and-sourced-object-roots.md)로 대체한다.
- 대체: [0051](0051-inline-names-and-prefab-membership.md)의 루트 Rename을 파일 Rename으로 처리하는 계약.
- 유지: [0052](0052-local-scripts-and-fixed-inherited-topology.md)의 상속 구조 고정.

## 배경과 제약

Inspector가 루트 이름을 에셋 파일명으로 덮어써 루트 교체 후 새 오브젝트가 기존 이름으로 보였다. 에셋 이름과 구성 오브젝트 이름은 서로 다른 책임이며, 아이콘이 이름 앞 공간을 차지하면 들여쓰기와 혼동될 수 있다.

## 대안과 판단 기준

파일명에 루트 이름을 계속 종속시키거나 두 이름을 독립적으로 저장하는 방식을 비교했다. 루트 교체·캡처 시 오브젝트 정체성 보존과 동일한 Rename 동작을 기준으로 독립 저장을 선택했다. 이름이 없는 기존 파일을 일괄 수정하지 않고 표시 기본값을 사용한다.

## 결정과 근거

형식 4의 선택적 최상위 name은 루트 오브젝트 이름이다. 부모로부터 이름을 상속할 수 있고 로컬 name은 재정의한다. 이름이 없으면 Inspector에서 LObject로 표시한다. 계층 Rename은 루트·자손 모두 오브젝트 이름을 변경하고, 에셋 브라우저 Rename은 파일만 변경한다. CLI prefab.child.rename은 --node root도 지원하며 GUI와 공용 검증을 사용한다. 루트 교체는 각 이름을 보존하고 캡처도 루트 이름을 저장한다.

Prefab 아이콘은 행 오른쪽의 돋보기 왼쪽에 표시하여 이름의 시작 위치를 변경하지 않는다. 부모 Prefab이 지정된 경우 루트 교체는 계속 금지하고, 오류에 상속 구조 제한을 명시한다. 저장 형식 번호와 레벨의 인스턴스 이름 규칙은 유지한다.

## 결과

- 긍정: 루트 교체와 파일 Rename이 오브젝트 이름을 바꾸지 않는다.
- 부정: 이름이 없는 기존 Prefab 루트는 파일명 대신 LObject로 표시된다.
- 중립: 기존 CLI 명령을 확장하며, 새 명령이나 데이터 마이그레이션은 필요하지 않다.
