# 0040. Prefab 편집 초안과 전체 저장 확인

- 상태: 채택
- 날짜: 2026-10-09
- 확장: [ADR 0030](0030-file-run-menu-and-document-history.md)의 문서 저장, [ADR 0031](0031-asset-operation-history.md)의 에셋 기록

## 배경과 제약

Inspector의 값 변경은 파일 저장 전에도 배치된 인스턴스와 Play에 반영되어야 한다. 다른 에셋으로 이동해도 미저장 편집을 유지하고, 전체 저장은 대상 목록을 확인한 후 실행한다.

## 대안과 판단 기준

- 매 변경 자동 저장은 편집과 파일 저장을 구분하지 못한다.
- 에셋 전환마다 저장을 강제하면 여러 문서의 편집 흐름을 막는다.
- 파일을 동시에 원자적으로 저장하는 별도 트랜잭션은 현재 요구보다 크다. 문서별 원자 쓰기와 실패 피드백을 유지한다.

## 결정 및 근거

EditorApp은 에셋 ID별 PrefabDocument 초안과 Undo 기록을 보관한다. Project의 에셋 읽기는 변경된 초안에 한해 메모리 직렬화 값을 반환한다. 깨끗한 문서는 디스크를 읽는다. 인스턴스의 별도 override가 우선하며 preview 캐시는 초안 변경 시 무효화한다. 편집 중인 모든 Prefab의 삭제를 보호한다.

Export의 검증과 패키징은 같은 Project 에셋 읽기를 사용한다. 미저장 Prefab 초안도 게임에 포함하며 편집용 원본 파일과 dirty 상태는 유지한다. 저장 강제보다 저장 전 Play·Export 결과를 일치시키는 방식을 선택한다. Refresh는 깨끗한 Prefab의 디스크 스냅샷이 실제로 달라졌을 때만 문서 데이터와 History를 교체한다. 같은 데이터의 반복 Refresh는 저장 이후 Undo와 Redo도 보존한다. 외부 파일 변경으로 새 기준값이 생긴 경우에는 이전 기록을 초기화한다.

Inspector의 Save와 Ctrl+S는 현재 문서를 저장한다. File → Save All 또는 Ctrl+Shift+S는 변경된 Prefab과 현재 변경된 레벨 목록을 체크박스로 표시하며 기본적으로 모두 체크한다. 행 클릭 또는 Space로 체크를 전환하고 확인한 대상만 저장한다. 체크 해제된 문서는 미저장 상태를 유지하며 모두 해제하면 쓰기 없이 닫는다. 미저장 새 레벨도 포함한다. 확인 전에는 쓰지 않고, 취소는 초안을 보존한다. 체크된 이름 없는 레벨은 확인 후 경로 입력 창을 연다. 저장 실패는 확인 창에 표시하며 실패한 문서의 dirty 상태를 보존한다. 이미 저장된 문서는 재시도 때 건너뛴다.

```text
EditorApp → PrefabDocument 초안 목록 / 현재 LevelDocument  (포함)
Project → 변경된 PrefabDocument                          (참조)
Save All Dialog → 저장 대상 목록                         (포함)
확인 콜백 → 각 문서의 save                              (의존)
```

## 예상 결과

- 긍정: 저장 전 변경 결과를 확인하고, 여러 Prefab을 편집한 뒤 한 번에 저장 대상을 검토할 수 있다.
- 부정: 뒤 문서의 저장이 실패하면 앞 문서는 이미 저장되어 있을 수 있다. 전체 문서 저장의 원자성은 보장하지 않는다.
- 중립: 현재 열린 레벨은 하나이며, Lua 소스 편집기·다중 레벨 문서 관리·자동 저장은 추가하지 않는다.
