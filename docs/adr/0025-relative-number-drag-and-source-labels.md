# 0025. 상대 마우스 숫자 드래그와 원본 이름 표시

- 상태: 채택
- 날짜: 2026-10-09
- 확장: [ADR 0023](0023-text-edit-and-component-group-layout.md)의 숫자 입력
- 확장: [ADR 0024](0024-collapsible-details-and-property-columns.md)의 헤더·대상 종류 표시

## 배경과 제약

사용자는 숫자 입력칸의 좌우 드래그 증감, 드래그 중 커서 숨김과 창 경계 없는 조절, 텍스트 커서 대신 테두리 강조를 요청했다. 인스턴스 종류는 원본 Prefab 이름, Prefab 종류는 부모 클래스 이름으로 표시한다. 펼친 헤더 아래의 높이 차이도 없애야 한다. 기존 문자 선택·IME·숫자 검증·override·스냅 저장·사용자 Inspector 폭을 유지한다.

## 대안과 판단 기준

- 같은 드래그를 문자 선택과 숫자 조절에 동시에 쓰면 의미가 충돌한다. 새로 포커스한 숫자 입력칸은 증감, 클릭 후 이미 편집 중인 칸은 문자 선택으로 구분한다.
- 절대 좌표 변화량만 쓰면 화면 가장자리에서 조절이 멈춘다. [LÖVE 상대 마우스 모드](https://love2d.org/wiki/love.mouse.setRelativeMode)와 mousemoved의 dx로 조절한다. 일반 클릭은 그대로 두고 4px 이상 이동했을 때만 상대 모드를 활성화한다.
- 매 움직임마다 스냅 설정 파일을 쓰면 불필요한 I/O가 늘고 Escape 복원이 어렵다. 메모리 값은 실시간으로 반영하고 파일 저장은 해제 시 수행한다.
- 표시 문자열을 저장하면 이름 변경과 동기화되지 않는다. 원본 에셋 ID와 클래스 로더의 표시 이름을 사용한다.

## 결정 및 근거

1. `editor/ui/number_drag.lua`가 숫자 드래그의 초기값·임계값·누적값·정밀도·마우스 모드 수명주기를 담당한다. Inspector, ClassInspector, ViewportControls는 의존하며 transient 드래그 상태를 소유한다. 콜백으로 각 대상에 검증된 숫자를 실시간 반영한다.
2. 일반 숫자·위치·회전은 1/px, 스케일과 Scale 스냅은 0.01/px이고 Shift는 1/10 감도다. Shift 전환은 현재값 이후 이동량에만 적용하여 값이 튀지 않는다. 회전은 기존 0~360 정규화, 스케일은 최소 0.01, 스냅은 최소 0.001, 일반 프로퍼티는 음수도 허용한다. 비유한 결과는 반영하지 않는다.
3. 활성화 시 이전 상대 모드·표시·grab 상태를 기록하고 상대 모드를 켜 커서를 숨긴다. 활성 드래그는 절대 위치가 고정되어도 dx로 계산한다. 종료·Escape·포커스 이탈·팝업 취소·앱 종료에서 마우스 상태를 복원한다. 이전 절대 모드에서는 처음 클릭한 위치로 복원한다.
4. 입력칸은 활성 숫자 드래그 중 테두리만 강조하고 텍스트 커서·범위 선택 배경을 표시하지 않는다. 값은 계속 표시한다. 클릭 해제만 한 뒤 재클릭하면 기존 TextEdit 문자 선택을 사용한다.
5. 마우스 해제는 현재값을 확정하고 Escape·포커스 이탈·팝업 전환은 초기값으로 되돌린다. 클래스 프로퍼티 복원은 기존 기본값과 비교하여 override를 정리한다. 스냅 설정은 드래그 중 메모리만 변경하고 해제 시 기존 저장 콜백을 한 번 호출한다.
6. PropertyLayout의 열린 헤더는 실제 헤더 영역인 32px, 닫힌 헤더는 26px에 맞춘다. 클릭 판정도 같은 영역을 사용한다. 인스턴스 종류는 원본 에셋의 현재 basename + Instance, Prefab 종류는 부모 모듈 이름 + Prefab이며 참조가 없는 내장 객체는 LObject로 표시한다. 인스턴스 Transform 위 간격만 12px 늘린다.

## 예상 결과

- 긍정: 화면 경계 없이 숫자를 조절하고 뷰포트 결과를 즉시 확인한다. 기존 문자 선택과 스냅 저장을 유지하며 종료 경로에서 커서가 숨은 채 남지 않는다. 대상의 원본을 Inspector에서 확인할 수 있다.
- 부정: 최초 숫자 입력칸 드래그는 문자 선택 대신 증감이다. 감도는 범용 기본값이며 프로퍼티별 사용자 감도 선언은 제공하지 않는다.
- 중립: JSON 스키마·Core lifecycle·컴포넌트 상속은 변경하지 않는다. 드래그 상태·마우스 상태·표시 이름은 authoring data에 저장하지 않는다.
