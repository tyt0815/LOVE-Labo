# 0052. 로컬 스크립트 확장과 상속 구조 고정

- 상태: 승인·구현
- 원본 연결이 있는 루트의 교체 금지는 [ADR 0055](0055-prefab-container-and-sourced-object-roots.md)로 대체한다. 상속 구성 내부 제한은 유지한다.
- 대체 범위: [0050](0050-attached-scripts-and-unified-assets.md)의 인스턴스 부착 금지, [0051](0051-inline-names-and-prefab-membership.md)의 단일 행 이름 편집.

## 배경과 제약

빈 LObject나 레벨 한 곳의 행동을 구성할 때마다 Prefab을 만드는 것은 불필요했다. 두 계층에 같은 드래그 의미를 제공하되 상속 원본과 다른 부모 관계·루트를 만들면 이후 상속 병합 규칙이 복잡해진다. 사용자는 상속 구조 변경을 금지하고 추가 부착과 값 재정의만 허용하기로 결정했다.

## 대안과 판단 기준

상속 계층까지 자유롭게 재배치하는 모델과 고정 모델을 비교했다. 원본 갱신의 예측 가능성과 데이터·참조 안정성을 기준으로 고정 모델을 선택했다. 상속 중 루트를 바꾸며 부모 연결을 끊는 대안은 채택하지 않았다. 인스턴스 로컬 스크립트는 구성 편의와 조합을 위해 허용한다.

## 결정과 근거

상속된 오브젝트의 부모·순서·루트·존재와 상속된 스크립트의 부착·순서를 변경하지 않는다. 오브젝트·스크립트 값과 이름은 재정의할 수 있다. 새 자손과 로컬 스크립트를 추가할 수 있고 로컬 항목은 이동·정렬·제거할 수 있다. 로컬 항목을 상속 항목 사이에 끼워 넣지 않으며, 원본 구조를 통째로 배치한 인스턴스의 루트 이동·삭제는 허용한다. 예전 제거 기록은 읽을 수 있지만 새 편집 명령으로 상속 제거를 만들지 않는다.

Level Hierarchy와 Prefab ObjectTree는 같은 TreeDrop 판정 유틸리티를 의존한다. 행 중앙은 부착, 현재 부모에 다시 드롭하면 디태치, 행 가장자리는 순서 변경이다. 레벨은 독립 루트로, Prefab은 해당 Prefab 루트 아래로 디태치한다. 부모 Prefab이 없는 Prefab에서는 자손을 루트 행 위에 드롭하여 루트를 교체하며 기존 루트는 새 루트의 자식으로 보존한다. 부착 ID·자손 ID와 내부 참조를 재연결하고 실패하면 초안을 복원한다. 로컬 계층 이동은 원본 참조와 명시적 재정의만 옮겨 이후 원본 갱신을 유지한다.

Add Script는 같은 행의 검색 가능한 선택 입력·스포이드·취소 기호로 전환한다. 기존 스포이드 선택 계약을 유지한다. 이름 편집에서 키 반복을 활성화하고 편집 종료 후 이전 설정을 복원한다. 파일명은 UTF-8 문자 경계에서 여러 줄로 줄바꿈하며 긴 입력은 현재 커서가 보이도록 표시한다.

## 결과

- 긍정: 빈 오브젝트와 인스턴스에서 행동을 직접 조합하고, 상속 구조 변경을 예측 가능하게 제한한다.
- 부정: 상속된 가지를 재구성하려면 원본을 편집하거나 새 독립 구성을 만들어야 한다.
- 중립: GUI·CLI는 같은 편집 제한과 이동 로직을 사용한다. 런타임 동적 부착 계약은 [ADR 0069](0069-script-identity-and-editor-authored-attachments.md)로 대체한다.
