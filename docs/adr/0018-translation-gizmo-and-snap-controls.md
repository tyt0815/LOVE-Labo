# 0018. 이동 기즈모와 뷰포트 스냅 컨트롤

- 상태: 채택
- 날짜: 2026-10-09
- 확장: [ADR 0001](0001-centered-viewport-origin.md)의 좌표 변환, [ADR 0014](0014-love-theme-panels-and-status-hints.md)의 패널 표현, [ADR 0017](0017-components-instance-properties-and-prefab-placement.md)의 Prefab 배치

## 배경과 제약

사용자는 A 키의 빈 객체 생성을 제거하고 기존 작은 정사각형 테두리를 이동 기즈모로 바꾸도록 요청했다. 오른쪽·위쪽 화살표는 축 이동을, 두 축 사이 사각형은 자유 이동을 지원한다. 뷰포트 우상단에는 제목 없이 스냅 체크박스와 단위 입력칸만 배치한다. 기존 중앙 원점, Y 양수 아래 방향, Edit/Runtime 분리 및 UI 포인터 캡처를 유지한다.

## 대안과 판단 기준

- 모든 객체에 기즈모를 그리면 겹친 객체의 선택·조작이 모호해진다. 선택한 객체 하나에만 표시하고 Sprite 영역 또는 Hierarchy에서 선택한다.
- 월드 크기를 고정하면 축소 시 핸들을 잡기 어렵다. 화면 픽셀 크기를 고정하되 이동량은 줌으로 나누어 월드 좌표로 변환한다.
- 스냅된 위치에 프레임별 delta를 더하면 작은 이동량이 계속 버려진다. 시작 위치와 누적 픽셀 delta로 새 위치를 계산한다.
- 도구 패널을 단순한 그림으로 넣으면 클릭·스크롤·키보드가 Scene View에 전달된다. 기존 Canvas의 상위 z 슬롯에 포커스 가능한 위젯으로 배치한다.

## 결정 및 근거

1. A 키 생성과 안내를 삭제한다. `Level:addLObject`는 데이터·코드·Prefab 배치를 위해 유지한다. 객체 클릭은 선택만 하며 드래그는 기즈모 핸들에서 시작한다.
2. SceneView는 편집 전용 drag/snap 상태를 소유한다. TranslationGizmo는 좌표·히트 영역·그리기를 담당하는 의존 모듈이며 상속·인터페이스 구현 관계는 없다. 위쪽 화살표 드래그에서 화면 위로 이동하면 Y가 감소한다.
3. 오른쪽/위쪽 축에서는 각각 X/Y만 변경하고 다른 좌표는 그대로 유지한다. 사각형은 두 좌표를 변경한다. 포인터 캡처로 뷰포트 밖까지 드래그하며 Escape는 시작 위치로 복원한다. 드래그 중 줌은 변경하지 않는다.
4. SnapControls는 Widget을 상속하고 SceneView에 의존한다. Scene Canvas가 위젯을 소유한다. 기존 공통 패널의 라운드·테두리를 사용하고 색은 전체 에디터의 `background` 역할을 사용한다. 제목 및 다른 버튼은 없다. Play의 Game View에서는 숨긴다.
5. 스냅 기본값은 꺼짐, 단위는 32 월드 단위다. 0보다 큰 유한 숫자만 적용하며 잘못된 입력은 이전 값을 유지한다. Enter·포커스 이동에서 확정하고 Escape에서 취소한다. 값은 에디터 세션 상태로 유지하고 레벨 파일에 저장하지 않는다.
6. 스냅은 월드 원점에 정렬한 가장 가까운 배수에 적용하며 중간값은 원점에서 먼 쪽으로 반올림한다. 기즈모 이동·Prefab 드롭·Ctrl+D 복제에 적용한다. Inspector의 직접 위치 입력과 기존 그리드 간격은 유지한다.

## 예상 결과

- 긍정: 축 이동과 자유 이동이 명확해지고 줌에서도 핸들을 잡기 쉽다. 스냅이 작은 이동에서도 누적되며 도구 입력이 객체 조작으로 새지 않는다.
- 부정: 기존 객체 본체 드래그 사용자는 선택 후 핸들을 잡아야 한다. 이미지를 표시하지 않는 객체는 Hierarchy나 기존 원점 히트 영역에서 선택해야 한다. 스냅 설정은 재실행 후 기본값으로 돌아간다.
- 중립: 저장된 좌표와 객체 식별자, Sprite 렌더링, Inspector, Play 데이터 분리는 바꾸지 않는다. 회전·크기 기즈모, 격자 간격 변경, 설정 저장은 포함하지 않는다.
