# 0015. 나눔스퀘어 라운드 동봉과 공통 글꼴 관리

- 상태: 채택
- 날짜: 2026-10-08
- 부분 대체: [ADR 0013](0013-browser-drag-moves-and-asset-colors.md)의 겹쳐 그리는 글리프 강조
- 확장: [ADR 0014](0014-love-theme-panels-and-status-hints.md)의 제목·라벨 표현

## 배경과 제약

사용자가 나눔스퀘어 라운드 ZIP을 제공하고 에디터에 적용하도록 요청했다. ZIP에는 글꼴 설치 프로그램이 들어 있으며 시스템 설치 없이 글꼴 파일을 에디터 리소스로 동봉해야 한다. 현재 시작 화면만 Windows 맑은 고딕 경로를 읽고 제목·썸네일은 LÖVE 기본 글꼴을 별도로 생성하여 일관되지 않았다.

## 대안과 판단 기준

- 시스템 글꼴을 설치하거나 OS 경로를 읽으면 배포·운영체제별 의존성이 남는다. 제공된 설치 프로그램에서 필요한 파일만 추출해 동봉한다.
- 모든 굵기를 포함하면 현재 UI에서 쓰지 않는 용량을 추가한다. Regular·Bold 두 파일만 사용한다.
- 글리프를 겹쳐 그리는 방식은 글꼴의 실제 Bold 형태와 다르다. Bold TTF를 크기별로 생성해 사용한다.
- 드롭다운 문자열에 v를 붙이면 아이콘과 값이 구별되지 않는다. 화살표를 도형으로 그리고 구분선으로 분리한다.

## 결정 및 근거

1. 제공된 TTF 설치 프로그램에서 수정하지 않은 NanumSquareRoundR.ttf·NanumSquareRoundB.ttf를 editor/fonts에 추출한다. 설치 프로그램은 실행하지 않고 저장소에 남기지 않는다. NAVER 저작권 고지와 SIL OFL 1.1 전문을 함께 둔다.
2. editor/fonts.lua가 크기·굵기별 캐시를 소유하고 시작 시 Regular 14px를 적용한다. 패널 제목은 Bold 15px, 프로퍼티 라벨은 현재 크기의 Bold, 중앙 썸네일은 Regular 24px, Lua 표식은 Bold 11px로 사용한다. UI.text는 실제로 선택한 굵기의 폭으로 생략을 계산하고 기존 폰트를 복원한다. Core나 게임 데이터에 글꼴 설정을 추가하지 않는다.
3. 공통 드롭다운은 오른쪽 28px의 화살표 영역과 구분선을 그린다. 파일 보기 드롭다운 폭은 142px로 늘려 텍스트와 아이콘 공간을 확보하고 Refresh와의 간격은 유지한다. 작은 버튼의 패딩도 폭에 맞춰 줄여 R 같은 문구를 생략하지 않는다.

## 예상 결과

- 긍정: 한글·영문과 제목·썸네일의 글꼴이 통일되고 시스템 설치 없이 배포할 수 있다. 실제 Bold를 사용하며 드롭다운 값과 화살표가 명확히 구분된다.
- 부정: 두 TTF 약 2MB가 에디터 배포에 추가된다. 새 글꼴의 글자 폭에 맞춰 버튼 너비와 여백을 조절해야 한다.
- 중립: 문서·프로젝트 파일 형식과 입력 처리·드롭다운 선택 방식은 유지한다.
