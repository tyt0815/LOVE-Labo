# 0001. Viewport 중앙을 기본 월드 원점으로 사용

- 상태: 채택
- 날짜: 2026-10-08

## 배경과 제약

사용자가 viewport의 기본 `(0, 0)`을 좌상단에서 중앙으로 변경하도록 요청했다. Scene View와 Game View의 좌표 표현을 일치시키되, 설계 문서의 Edit/Runtime 상태 분리와 기존 Transform 데이터는 유지해야 한다. 기존 ADR은 없다.

## 대안과 판단 기준

- 최초 배치 시 camera offset에 절반 크기를 넣으면 구현은 작지만, 크기 변경 시 별도 보정이 필요하고 camera offset의 의미가 불명확해진다.
- 좌표 변환에 현재 viewport 중앙을 포함하면 크기 변경을 자연스럽게 반영하고 pan 이동량을 독립적으로 유지할 수 있다.

## 결정과 근거

Scene View와 Game View의 기본 월드 원점은 각 viewport 중앙으로 정한다. Scene View의 camera offset은 중앙에서의 화면 픽셀 이동량이며 줌, 입력 역변환, 그리드와 선택 객체 포커스에도 같은 기준을 적용한다. Game View는 독립적인 1:1 변환을 사용한다. 명시적인 viewport가 없으면 전체 창 중앙을 사용한다.

## 결과

- 긍정: 원점 주변의 양수·음수 좌표를 처음부터 볼 수 있고 크기 변경 후에도 중앙 기준을 유지한다.
- 부정: 기존 레벨의 같은 좌표가 이전보다 화면 오른쪽 아래에 표시된다.
- 중립: 저장된 Transform, X 양수 오른쪽/Y 양수 아래 방향, Edit/Runtime 상태 분리는 유지된다. Scene View를 pan하면 원점도 이동한다.
