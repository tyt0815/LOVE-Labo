# 0055. Prefab 컨테이너와 원본을 참조하는 오브젝트의 루트 교체

- 상태: 승인·구현
- 부분 대체: [0052](0052-local-scripts-and-fixed-inherited-topology.md), [0054](0054-prefab-root-object-names.md)의 원본 연결이 있는 루트 교체 금지.

## 배경과 제약

루트 오브젝트의 Parent Prefab을 에셋 전체의 상속으로 해석하여 루트 교체를 금지했다. 사용자는 상속된 구성 내부의 관계를 고정하려는 의도였으며, 계층을 담는 Prefab 에셋과 원본을 참조하는 오브젝트를 구분하기로 했다. 새 루트를 추가해 기존 구성 전체를 그 아래에 두어도 원본 구성 내부는 바뀌지 않는다.

## 대안과 판단 기준

교체를 계속 금지하거나 원본 연결을 끊고 유효 값을 독립화하는 대안과, 기존 원본 연결을 가진 루트를 통째로 보존하는 대안을 비교했다. 원본 갱신 수신, 구성 내부의 안정성과 오브젝트 이름·참조 보존을 기준으로 마지막 방식을 선택했다.

## 결정과 근거

Prefab 에셋은 한 루트와 자손을 담는 컨테이너이며 각 오브젝트의 definitionReference는 해당 오브젝트가 사용하는 원본 Prefab이다. Parent Prefab이 있는 현재 루트도 로컬 자손을 새 루트로 지정하여 그 아래로 옮길 수 있다. 기존 루트의 원본·부착·상속 자손·로컬 재정의는 유지하고 새 루트는 자신의 원본·이름·부착을 사용한다. 상속된 자손을 원본 구성에서 꺼내 새 루트로 지정하거나 부모·순서를 변경하는 것은 계속 금지한다.

```text
Prefab 에셋 (포함)
└ 새 루트 LObject
  └ 기존 루트 LObject ── 원본 참조 → BasePrefab
    └ BasePrefab이 생성한 상속 자손
```

교체 시 로컬 바인딩과 제거 경로를 새 경로로 재매핑한다. 원본이 제공하는 바인딩은 기존 루트의 새 위치를 기준으로 다시 해석한다. 중첩 원본을 병합할 때 로컬 부분 레코드가 상속 여부를 해제하지 않도록 한다. 기존 GUI 드래그와 CLI prefab.child.move가 공용 로직을 사용하며 저장 형식 번호는 변경하지 않는다.

## 결과

- 긍정: 원본을 유지하면서 오브젝트를 새 컨테이너 루트 아래에 구성할 수 있다.
- 부정: 루트 교체 후 내부 경로가 바뀌므로 로컬 참조와 제거 기록을 재매핑해야 한다.
- 중립: Parent Prefab은 계속 선택 오브젝트의 원본이며 에셋 전체의 부모 필드를 추가하지 않는다.
