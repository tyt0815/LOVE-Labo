# 0075. Inspector의 범위 탭과 Script 내부 프로퍼티 그룹

- 상태: 승인·구현
- 관련: [0024](0024-collapsible-details-and-property-columns.md), [0069](0069-script-identity-and-editor-authored-attachments.md), [0074](0074-scoped-scripts-and-screen-drawing.md)

## 배경과 제약

빈 공간 선택으로 현재 레벨 설정을 표시하면 대상이 드러나지 않는다. Project 부착 편집 진입점도 필요하다. 프로퍼티 그룹을 각각 Script처럼 같은 깊이로 표시하면 실제 부착 개수와 소속을 혼동한다. 미저장 문서·Undo/Redo·Prefab 상속 구성과 기존 프로퍼티 편집 계약을 유지한다.

## 대안과 판단 기준

프로젝트 루트 행 선택은 폴더 탐색으로 보이고, 빈 공간 클릭은 설정 진입점으로 발견하기 어렵다. Inspector에 Selection·Project 탭을 두고 명시적 범위 선택을 제공한다. 반복된 Script 이름에 그룹명을 붙이는 평면 표시 대신 부착 헤더 아래에 그룹을 중첩한다.

## 결정 및 근거

Project 탭에서 프로젝트 부착을 편집한다. 레벨 에셋·Object 선택은 Selection으로 전환한다. 빈 공간은 선택을 해제하고 빈 Inspector를 표시한다. 레벨 에셋을 한 번 선택하면 실행 레벨을 바꾸지 않고 해당 문서의 부착·프로퍼티·Main Camera를 편집한다. 현재 열린 레벨은 같은 문서를 공유하고, 다른 레벨은 별도 문서 초안과 기록을 사용한다. Project 설정도 별도 문서 기록·저장 및 Save All에 포함한다.

캐시된 LevelDocument는 Project의 에셋 ID와 연결하고 저장 시 현재 위치를 다시 해석한다. 파일·폴더 이동 및 Undo/Redo에서 캐시 경로를 갱신하며, Save As는 새 ID로 연결하고 이전 ID의 캐시 별칭을 제거한다. 레벨을 다시 선택하거나 열 때 미저장 문서는 유지하고 clean 문서는 디스크에서 확인한다. 저장 스냅샷이 달라졌으면 같은 문서의 Level 데이터를 교체하고 Undo 기준도 새로 시작한다. 경로만 캐시하면 이전 위치에 파일을 재생성할 수 있고, clean 문서를 무조건 재사용하면 외부 변경을 덮어쓸 수 있으므로 이 두 조건을 분리해 처리한다.

각 부착은 이름 (타입) 헤더 하나로 표시한다. 그룹 없는 필드는 바로 아래, 명시적 프로퍼티 그룹은 그 부착 안에 접기 가능한 헤더로 표시한다. 내장 Transform과 부착 Script 헤더의 기존 박스·배경·패딩은 유지한다. 내부 프로퍼티 그룹 헤더는 들여쓰지 않고 일반 프로퍼티 행과 배경·패딩·이름 시작 위치를 맞춘 뒤 앞에 열기·닫기 화살표만 추가한다. 내부 그룹을 펼치면 자식 행 높이의 합만큼 공간을 확보하고 헤더를 제외한 영역에 기존 Script 박스와 같은 배경과 둥근 테두리를 그린다. 박스의 왼쪽 경계와 프로퍼티 이름만 안으로 들어가며 값·재설정 영역의 위치와 크기는 일반 행과 같다. 단독 세로 안내선은 사용하지 않는다. 이름·값 사용 가능 너비는 기본 1:1이며 공용 PropertyLayout.NAME_COLUMN_RATIO로 조정한다. 재설정 버튼과 공통 패딩은 비율에서 제외한다. 이름 열의 기본 여백은 화살표와 겹치지 않도록 유지한다. 원본 찾기·부착 제거·이름 변경·순서 변경은 부착 헤더에만 제공한다. 필드 위치 찾기는 상위 부착과 하위 그룹을 함께 펼친다.

원본 찾기는 source의 공개 이름·에셋 ID·경로를 프로젝트 참조 계약으로 정규화한 뒤 파일 위치로 이동한다. 파일 경로용 getAssetId에 UUID를 바로 넣지 않는다.

## 예상 결과

- 긍정: 프로젝트·레벨 설정의 진입점과 부착·그룹 소속이 명확하다.
- 부정: 중첩 헤더와 탭에 세로 공간이 추가로 필요하다.
- 중립: 그룹 접기 상태는 UI 상태이며 저장 데이터에 추가하지 않는다. 폴더 트리의 프로젝트 행은 탐색 역할을 유지한다.
