# 0080. Script 활성 상태는 헤더 토글로 편집하고 프로퍼티 이름은 문장형으로 표시한다

- 상태: 채택·구현
- 날짜: 2026-10-16
- 표시 확장: [0069](0069-script-identity-and-editor-authored-attachments.md), [0075](0075-inspector-scope-tabs-and-nested-script-groups.md)

## 배경과 제약

공통 Inspector 프로퍼티는 enabled 하나인데 이를 Script 그룹 안에 두면 활성 상태를 확인하기 위해 펼쳐야 한다. Motion 예제가 enabled를 Movement 그룹으로 재선언하여 같은 속성의 위치도 달라졌다. Project·Level·Object·Prefab에서 동일한 조작을 제공하면서 기존 저장 키·CLI·런타임 API·상속 재정의·Undo를 유지해야 한다.

## 대안과 판단 기준

enabled를 숨기기만 하면 GUI에서 실행 여부를 설정할 수 없다. Script 그룹을 유지하면 한 필드 때문에 접기 조작이 필요하다. 헤더 토글은 부착 소속과 상태를 함께 표시하고 접힌 상태에서도 조작할 수 있다. 프로퍼티 키를 직접 바꾸면 기존 코드와 저장값을 깨뜨리므로 표시 문자열만 변환한다.

## 결정과 근거

모든 부착 Script 헤더의 돋보기 왼쪽에 활성 토글을 둔다. 일반 프로퍼티 행에서는 부착의 enabled를 제외하며 비어 버린 그룹도 표시하지 않는다. 헤더 접기·원본 찾기·제거와 히트 영역을 분리하고, 읽기 전용 대상은 상태만 표시한다. 기존 setProperty와 기록 경로를 사용하여 상속 기본값·재정의·저장·Undo를 공유한다. enabled의 타입·기본값·런타임 동작과 CLI 키는 그대로다. Motion 예제의 중복 선언은 제거한다.

프로퍼티 레이블은 camelCase·PascalCase·밑줄의 단어 경계를 공백으로 나누고 첫 단어만 대문자로 시작하는 문장형으로 표시한다. sortingOrder·sorting_order·sorting_Order는 모두 Sorting order다. URL·ID처럼 대문자로 구성된 약어는 유지한다. Transform의 기존 명시적 축·각도 표시는 유지하며 부착 이름·스크립트 타입·그룹명은 자동 변환하지 않는다. 툴팁에는 원래 키를 남기고 저장·참조·정렬·CLI·코드에서는 원래 이름을 사용한다.

## 예상 결과

- 긍정: 모든 부착의 활성 상태를 같은 위치에서 확인하며 코드식 이름도 쉽게 읽을 수 있다.
- 부정: 헤더의 버튼 영역이 늘어나 긴 부착 이름에 사용할 폭이 줄어든다.
- 중립: 데이터 형식·모듈 관계·실행 생명주기는 변경하지 않는다. 공통 프로퍼티가 실제로 추가되면 당시 요구에 맞게 배치를 검토한다.
