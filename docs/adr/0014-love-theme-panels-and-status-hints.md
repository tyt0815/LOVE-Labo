# 0014. LÖVE 기본 테마·독립 패널과 전역 호버 힌트

- 상태: 채택
- 날짜: 2026-10-08
- 부분 대체: [ADR 0009](0009-editor-settings-and-themes.md)의 어두운 기본 색상
- 확장: [ADR 0013](0013-browser-drag-moves-and-asset-colors.md)의 아이콘과 드래그 안내

## 배경과 제약

사용자는 LÖVE 공식 홈페이지의 색상으로 기본 테마를 바꾸고, 제공한 VS Code 화면처럼 배경과 패널 경계를 구별하며 제목을 강조하도록 요청했다. 브라우저에 있던 하단 안내는 창 전체의 상태 표시줄로 옮기고 호버한 UI의 힌트를 표시해야 한다. 아이콘 중앙 텍스트는 Lua 표식 유무에 따라 크기·위치가 달라지면 안 된다.

## 대안과 판단 기준

- 패널 색만 바꾸면 서로 붙은 기존 레이아웃에서 배경과 독립 표면을 구별하기 어렵다. 내부 여백·둥근 외곽선·별도 제목 색과 크기를 공통 UI 헬퍼로 제공한다.
- 브라우저 내부 상태 문구는 인스펙터·계층의 힌트를 표현하기 어렵다. 프로젝트 에디터의 하단 영역을 따로 예약한다.
- 모든 힌트를 App에 버튼별로 하드코딩하면 위젯 추가 시 위치 계산이 중복된다. 위젯의 힌트와 공통 렌더링 헬퍼의 실제 사각형 등록을 함께 사용한다.
- Lua 표식을 피하려고 중앙 글자를 옮기면 같은 종류 아이콘의 정렬이 어긋난다. 중앙 텍스트를 공통 24px·동일 좌표로 고정하고 표식은 우하단에 둔다.

## 결정 및 근거

1. [공식 CSS](https://love2d.org/style/style.css?b)의 E0F4FC 배경, 383F4A 본문, 1B4D68 제목, EA316E·25AAE1 강조색과 [box.svg](https://love2d.org/style/box.svg)의 B1E3FA 패널색을 기본 팔레트에 사용한다. 경계·선택·오버레이는 해당 색의 알파를 조절한다. 기본 원본은 코드 내부에만 두고 설정을 default로 변경한다. Atom One Light는 별도 선택 가능한 JSON으로 유지한다.
2. panelBorder·panelTitle 색 역할을 추가한다. 계층·인스펙터·브라우저는 6px 내부 여백과 둥근 외곽선을 갖고, 제목은 15px 굵은 글씨와 구분선으로 표시한다. Scene·Game View의 제목도 같은 글씨 규칙을 사용한다. 패널 크기 조절과 뷰포트 중앙 원점은 유지한다.
3. 프로젝트 에디터는 하단 26px을 상태 표시줄에 예약한다. 브라우저 내부의 안내 행은 없애고 해당 공간은 탐색 콘텐츠에 사용한다. 계층·뷰포트·인스펙터와 크기 조절 입력은 상태 표시줄로 내려오지 않는다. 상태 표시줄은 별도 카드 없이 전체 배경 위에 그린다.
4. 각 프레임의 포인터 위치로 버튼·입력칸·선택 목록·경로 등의 힌트를 등록한다. Root는 포인터 위치의 위젯과 부모에서 일반 영역의 힌트를 구한다. 팝업을 그릴 때 뒤쪽 컨트롤의 힌트를 비우고 팝업의 안내를 우선한다. 드래그 중에는 이동 안내를 우선하며 실제 오류는 일반 힌트와 함께 보존한다.
5. 종류별 아이콘의 중앙 텍스트 크기와 좌표는 Lua 여부와 무관하다. 중앙은 24px, 우하단 Lua 표식은 11px이다. 흰 아이콘 배경과 종류별 색 역할은 유지한다.

## 예상 결과

- 긍정: 기본 테마의 브랜드 색이 통일되고 패널 제목·경계·배경이 명확해진다. 상태 표시줄에서 포인터 대상의 동작을 즉시 확인하며 아이콘의 글자 정렬이 일관된다.
- 부정: 기존 사용자 테마에서 panelBorder·panelTitle을 생략하면 LÖVE 기본값을 상속한다. 전체 작업 영역은 상태 표시줄 높이만큼 줄어든다.
- 중립: 기존 테마 선택·기본값 복구 계약과 문서 데이터 형식은 유지한다. 레이아웃 배치는 바뀌지 않고 패널 표현과 하단 영역을 조정한다.
