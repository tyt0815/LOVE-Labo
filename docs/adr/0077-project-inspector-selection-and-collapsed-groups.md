# 0077. 빈 선택과 메뉴의 Project Inspector 및 기본 접힘 그룹

- 상태: 채택·구현
- 관련: [0075](0075-inspector-scope-tabs-and-nested-script-groups.md)
- ADR 0075의 범위 탭·빈 선택 동작과 프로퍼티 그룹 초기 열림 상태를 대체한다.

## 배경과 제약

Selection·Project 탭은 Inspector의 진입점을 복잡하게 만든다. 사용자는 이전의 단일 Inspector 배치를 복원하고 빈 공간 선택 또는 Project 메뉴로 프로젝트 설정을 열기를 원한다. 레벨은 계속 에셋을 명시적으로 선택해 편집한다. 문서별 Save·Save All·Undo/Redo와 편집 중 값 확정 계약을 유지한다. 스크립트의 프로퍼티 그룹은 초기에 접어서 필요한 항목만 펼칠 수 있어야 한다.

## 대안과 판단 기준

탭 유지나 에셋 브라우저 루트 폴더를 프로젝트 설정 진입점으로 사용하는 대안은 현재 사용자의 요구와 맞지 않는다. 빈 선택만 사용하면 진입점을 찾기 어려울 수 있으므로 Project 메뉴에 Inspector 항목을 함께 제공한다. 메뉴를 누를 때 현재 오브젝트를 선택 해제하는 대신 Inspector 대상만 명시적으로 바꿔 기존 선택을 보존한다.

## 결정과 근거

Inspector 범위 탭과 관련 높이·클릭 영역을 제거한다. Scene·Hierarchy의 빈 선택, Asset Browser의 빈 선택은 Project Inspector를 표시한다. Project → Inspector도 같은 대상을 열고 기존 Scene 선택은 유지한다. 이후 오브젝트나 에셋을 선택하면 그 대상의 Inspector를 표시한다. 프로젝트 Inspector에는 오브젝트 미리보기를 표시하지 않는다.

빈 선택 때문에 자동으로 Project Inspector가 표시될 때에는 Project와 현재 레벨 중 최근 작업의 Undo/Redo 순서를 따져 Scene 작업의 되돌리기를 막지 않는다. 메뉴로 명시한 Project Inspector에서는 프로젝트 문서 기록을 사용한다. 레벨 에셋 초안과 Prefab의 별도 기록은 유지한다.

스크립트 부착 안의 명시적 프로퍼티 그룹은 처음 접힌 상태로 만든다. Script 부착 헤더·내장 Transform의 기존 초기 상태는 유지한다. 사용자가 펼친 상태는 같은 에디터 세션의 UI 상태로 보존하고, 프로퍼티 위치 찾기는 상위 부착과 필요한 내부 그룹을 자동으로 펼친다. 접힘 상태는 프로젝트나 레벨 데이터에 저장하지 않는다.

## 예상 결과

- 긍정: 단일 Inspector 배치로 프로젝트·레벨·객체를 편집하고, 긴 프로퍼티 목록을 필요한 그룹만 펼쳐 확인한다.
- 부정: 빈 공간을 선택하면 Project 설정이 표시되므로 선택 해제와 Inspector 비우기는 같은 동작이 아니다.
- 중립: Script 실행·데이터 형식과 문서 저장 범위는 바꾸지 않는다. 기존 메뉴·선택·그룹 모델을 재사용한다.
