# 0096. 원본과 분리한 미저장 초안 복구

- 상태: 채택·구현
- 관련: [0040](0040-prefab-drafts-and-save-all-review.md), [0089](0089-guide-and-adr-documentation.md)

## 배경과 제약

종료·충돌 후 Level·Prefab·Project Script 편집을 복구하되 원본 파일과 PIE의 임시 상태를 섞지 않아야 한다. 기존 원자 쓰기를 재사용하며 복구 기록 실패도 기존 정상 사본을 손상시키지 않는다.

## 대안과 판단 기준

원본 자동 저장은 사용자의 저장 시점을 바꾼다. 모든 Undo 기록을 저널로 보관하는 방식은 현재 필요한 마지막 편집 내용 복구보다 복잡하다. 문서 직렬화 스냅샷을 별도 보관한다.

## 결정 및 근거

RecoveryStore는 변경된 편집 문서만 2초 간격과 정상 종료 때 검사한다. 변경되지 않은 스냅샷은 다시 쓰지 않는다. .labo/Recovery 아래 세션별 JSON을 원자 교체하며 빈 새 레벨은 편집 후부터 포함한다. PIE 상태와 Undo 이력은 기록하지 않는다.

프로젝트를 열 때 이전 사본을 문서별로 선택해 미저장 초안으로 복원한다. 기준 스냅샷과 현재 원본이 다르면 외부 변경을 표시하고 기본 선택을 해제한다. 같은 문서의 복구 버전은 한 번에 하나만 선택한다. Later는 사본을 보존하고 Discard copies는 명시적으로 삭제한다. 복원한 내용을 새 세션 사본에 성공적으로 기록한 뒤 선택한 이전 기록만 정리한다. 사라진 레벨은 이름 없는 문서로 복원한다. 등록을 잃은 Prefab은 오류와 사본을 보존한다.

RecoveryStore ──참조──> 편집 문서 목록·공용 직렬화기·원자 파일 쓰기. Runtime World는 복구 입력에 포함하지 않는다.

RecoveryStore는 복원한 모든 LevelDocument를 직접 보관한다. 원본이 사라져 에셋 캐시에 등록할 수 없는 레벨도 현재 문서 전환과 무관하게 수집하며, 파일로 저장하기 전까지 기준 스냅샷과 같은 내용도 보존한다. 이전 에셋 ID와 복구 문서 식별자를 새 사본에 유지하므로 여러 미등록 레벨을 다음 세션에서도 구분해 복원할 수 있다.

현재 문서 전환은 모든 선택 문서 복원과 사본 이전이 성공한 뒤로 미룬다. 중간 문서나 새 사본 쓰기가 실패하면 현재 문서와 복구 대화상자를 유지해 오류를 표시하고 재시도를 허용한다. 같은 대화상자의 재시도는 이미 복원한 문서를 재사용해 중복 사본을 만들지 않는다.

## 예상 결과

- 긍정: 원본과 미저장 초안을 분리하며 실패·외부 변경 상황에서 복원 선택권을 보존한다.
- 부정: 마지막 기록 이후 최대 약 2초의 편집은 유실될 수 있다. 여러 세션의 사본은 사용자가 버전을 선택해야 한다.
- 중립: 파일 저장·Export·Undo의 기존 계약은 유지한다. 외부 Lua 편집기 버퍼는 복구하지 않는다.
