# 0022. 세 축 회전 기즈모와 활성 축 표시

- 상태: 채택
- 날짜: 2026-10-09
- 부분 대체: [ADR 0021](0021-begin-play-and-orthographic-rotation.md)의 Z 전용 회전 기즈모

## 배경과 제약

사용자가 위·오른쪽 반지름 선과 두 선을 잇는 호로 회전 기즈모를 변경하도록 요청했다. 위쪽 선은 X, 오른쪽 선은 Y, 호는 Z 회전이다. 조작 중에는 선택한 축만 표시하고 X/Y는 지름선으로 연장하며 Z는 전체 원을 표시한다. 기존 직교 투영·회전 저장·Rot 스냅·취소 계약을 유지한다.

## 대안과 판단 기준

- X/Y도 마우스의 극각을 사용하면 직선 핸들의 축 방향 드래그에서 각도가 변하지 않는다. 선택한 화면 축의 누적 이동량을 각도로 바꾼다.
- 로컬 회전 방향을 핸들에도 투영하면 옆면 상태에서 핸들이 사라지거나 두 선이 겹칠 수 있다. 요청한 고정 위·오른쪽 방향을 사용하여 모든 각도에서 조작할 수 있게 한다.
- 원 전체를 기본 상태에서 표시하면 선과 호의 역할 구분이 어렵다. 기본 호는 우상단 ¼원이고, 선택 시에만 해당 축의 지름선 또는 Z 전체 원으로 확장한다.

## 결정 및 근거

1. TransformGizmo의 기존 rotate 모드 안에서 세 핸들을 지원한다. 위쪽 선의 X 회전은 axisX 색, 오른쪽 선의 Y 회전은 axisY 색, 호의 Z 회전은 axisZ 색을 사용한다. 원점 근처는 축 선택에서 제외하고 호 끝점은 선 핸들 판정을 우선한다.
2. X/Y 드래그는 화면 1px당 1도로 변환한다. 위쪽 이동은 X 증가, 오른쪽 이동은 Y 증가다. 줌과 무관하게 누적 이동량에 Rot 스냅을 적용한 뒤 초기 각도에 더하고 0 이상 360 미만으로 정규화한다. 해당 회전 필드만 변경한다.
3. X/Y 드래그 중에는 반대편까지 늘린 지름선과 활성 각도만 표시한다. 다른 선과 호는 숨긴다. Z 드래그는 전체 원과 기존 각도 표시선을 사용하고 ±180도 경계를 감싼 극각 변화량을 적용한다.
4. SceneView의 기존 드래그 캡처·Escape 취소·모드 변경 취소를 공유한다. 해제·취소 후 기본 ¼원 형태로 복귀한다. Inspector·저장·Runtime의 Transform 구조는 변경하지 않는다.

## 예상 결과

- 긍정: 뷰포트에서 세 회전값을 조절하고 활성 축을 명확히 볼 수 있다. 모든 회전 각도에서도 화면 핸들을 선택할 수 있다.
- 부정: 위쪽 선이 X, 오른쪽 선이 Y 회전을 의미하므로 이동 기즈모와 방향별 축 역할이 다르다. X/Y 감도는 고정 1도/px이며 감도 설정은 제공하지 않는다.
- 중립: X/Y 기울기는 기존 직교 투영이며 3D 카메라·원근·깊이 정렬을 추가하지 않는다. 클래스·컴포넌트 상속과 저장 스키마는 유지한다.
