# 0053. 원본 소속에 따른 Prefab 범위선

- 상태: 승인·구현
- 대체: [0051](0051-inline-names-and-prefab-membership.md)의 소속 배경색과 조상 기반 묶음 판정.

## 배경과 제약

배경색은 행 선택과 겹치고 제한된 색을 재사용하여 소속 구분이 모호했다. Inspector는 가까운 조상을 따라 빈 자손까지 같은 묶음으로 표시했다. 사용자는 직접 추가한 오브젝트를 구분하고 부모 없는 오리지널은 별도 표시하지 않기를 요청했다. 일반 부모·자식 관계와 원본 Prefab 소속은 다른 개념이다.

## 대안과 판단 기준

글자색, 배경색, 루트 아이콘만 사용하는 방식과 아이콘·범위선 조합을 비교했다. 색을 기억하지 않아도 루트와 구성 범위를 읽고, 일반 행 선택과 구분할 수 있는 조합을 선택했다. 소속 판정은 계층상의 조상만으로 추정하지 않고 해석된 상속 여부와 레벨의 Prefab 생성 경로를 사용한다.

## 결정과 근거

Prefab 묶음의 루트에 상자 아이콘, 구성 행 왼쪽에 범위선을 표시한다. 선택한 묶음의 선만 강조하고 행 배경은 일반 선택 표시를 유지한다. 중첩 원본은 자기 루트에서 별도 묶음을 시작한다. 로컬 빈 자손은 부모 묶음에서 제외하고 해당 행에서는 선을 끊는다.

Inspector에서는 부모 Prefab이 없는 오리지널 루트와 직접 작성한 자손을 일반 행으로 표시한다. 파생 Prefab 루트와 상속된 자손은 부모 원본의 묶음이며, 로컬로 추가한 중첩 Prefab은 해당 원본의 묶음이다. 레벨의 배치 루트는 부모 원본의 유무와 무관하게 배치한 Prefab의 묶음을 시작하고 생성 자손만 공유한다. 같은 에셋을 두 번 배치해도 별도 인스턴스 묶음이다. 돋보기는 표시된 묶음의 원본을 찾는다. 저장 형식과 런타임 동작은 변경하지 않는다.

## 결과

- 긍정: 원본 소속과 직접 추가한 자손을 구분하고, 색상에 의존하지 않는다.
- 부정: 로컬 자손·중첩 묶음이 끼어 있으면 범위선이 여러 구간으로 나뉜다.
- 중립: 기존 GUI 찾기 및 CLI Prefab 조회·검증 명령을 재사용한다. 새 CLI 명령은 필요하지 않다.
