# 0004. 실행 인자로 프로젝트 바로 열기

- 상태: 채택
- 날짜: 2026-10-08

## 배경과 제약

개발 중 테스트 프로젝트를 매번 시작 화면에서 선택하는 작업을 줄여야 한다. 기존 프로젝트 생성·열기 검증과 오류 처리, 평소의 시작 화면 진입 흐름을 유지한다.

## 대안과 판단 기준

- 최근 프로젝트 자동 열기는 편하지만 실행할 테스트 대상을 명시적으로 구별하기 어렵고 지속 설정이 필요하다.
- 코드에 테스트 프로젝트 경로를 넣으면 개발자 환경과 일반 실행이 결합된다.
- 실행 인자는 IDE·실행 스크립트에서 대상을 명시할 수 있고 별도 설정 저장이 필요 없다.

## 결정 및 근거

`love . --project <프로젝트 폴더>`로 실행하면 시작 화면의 열기 동작을 재사용하여 프로젝트에 바로 진입한다. 절대 경로와 실행 작업 폴더 기준 상대 경로를 지원한다. 경로 누락·중복 또는 프로젝트 열기 실패는 시작 화면에서 오류로 표시한다. 프로젝트를 생성하거나 이전 프로젝트를 임의로 대신 열지 않는다.

옵션 없는 실행은 기존 시작 화면을 사용한다. `--test`는 프로젝트 진입보다 우선하며 자동화 테스트만 실행한다.

## 예상 결과

- 긍정: 테스트 프로젝트를 한 번의 실행으로 열 수 있고 개발자별 절대 경로를 코드에 저장하지 않는다.
- 부정: 실행 설정의 경로가 유효하지 않으면 시작 화면에서 수정해야 한다.
- 중립: 프로젝트 형식, 에셋 탐색과 레벨 연결 범위는 변경하지 않는다.
