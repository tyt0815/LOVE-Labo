# 0020. 독립 스냅 설정·회전 정규화와 Inspector 선택 유지

- 상태: 채택
- 후속 부분 대체: [ADR 0021](0021-begin-play-and-orthographic-rotation.md)의 단축키 전용 모드 선택·작은 스냅 패널
- 날짜: 2026-10-09
- 부분 대체: [ADR 0019](0019-transform-modes-and-relative-snap.md)의 이동 전용·세션 전용 스냅과 무제한 회전값
- 확장: [ADR 0012](0012-lua-classes-properties-and-unsaved-levels.md)의 Inspector 대상 선택

## 배경과 제약

사용자는 회전값의 범위를 제한하고 Move/Rot/Scale 각각의 스냅 토글과 값을 유지하도록 요청했다. 스냅 컨트롤은 이름 버튼과 값 입력칸을 가로로 배치하고 기즈모 선을 원점부터 이어야 한다. 프리팹 선택 후 인스턴스를 선택했는데 Inspector 클릭에서 프리팹으로 돌아가는 버그도 수정해야 한다. 추가 요청으로 선택 인스턴스의 렌더링 컴포넌트 외곽을 표시한다. 기존 Transform·Prefab override·Edit/Runtime 분리 계약을 유지한다.

## 대안과 판단 기준

- 회전값은 0~360 또는 -180~180으로 표현할 수 있다. 하나의 정규화 함수를 공유하고 음수·여러 바퀴 값도 받아들이는 0 이상 360 미만 표현을 선택한다. 드래그의 내부 누적 각도는 유지해 경계에서 조작이 튀지 않게 한다.
- 하나의 스냅 값을 모드 변경마다 덮어쓰면 단위가 다른 이동·각도·배율 설정을 잃는다. 모드별 `{enabled, unit}`를 유지한다. 사용자 요청의 저장은 재시작 후 복원까지 지원한다.
- 스냅 설정을 레벨이나 기존 테마 파일에 넣으면 문서 dirty 상태·색상 설정과 결합된다. 사용자 저장 폴더의 독립 설정 파일에 기록하고 저장 함수를 주입해 테스트를 사용자 파일과 분리한다.
- Inspector 표시를 현재 포커스 패널로 추론하면 클릭 시 선택 출처가 사라진다. 입력 포커스와 마지막 선택 출처를 별도로 유지한다.
- 투명 이미지 픽셀 외곽 추적은 이미지 처리·캐시가 추가된다. 요청에서 허용한 Sprite 이미지 크기 사각형을 같은 Transform으로 그린다.

## 결정 및 근거

1. Core Transform의 `normalizeRotation`을 복사·저장·Inspector 확정·기즈모 회전에 적용한다. 일반 프로젝트 런타임 코드는 rotation을 직접 변경할 수 있지만 편집·저장·로드 경계에서는 360으로 감싼다.
2. SceneView의 `snapSettings`는 translate/rotate/scale별 상태다. 기본값은 모두 꺼짐, 단위는 32 월드 단위·15도·0.1 배율 단위다. 독립 이름 버튼은 스냅만 토글하고 W/E/R 버튼·단축키는 모드만 바꾼다.
3. 이동과 회전은 시작값에 스냅한 누적 변화량을 더한다. 스케일 축은 해당 축의 배율 변화량을 스냅하고 중앙 균등 스케일은 초기 X 변화량을 기준으로 두 축의 비율을 유지한다. 0.01의 기즈모 스케일 하한과 Escape 복원을 유지한다.
4. `editor/snap_settings.lua`는 설정 검증·복사·로드·저장을 담당하는 모듈이다. Host는 EditorApp에 초기 설정과 저장 콜백을 주입한다. 변경 확정·토글마다 `viewport-settings.json`을 LÖVE 사용자 저장 폴더에 원자적으로 저장한다. 누락·잘못된 설정은 기본값으로 복원하고 저장 실패는 편집 상태를 보존하며 UI 오류로 알린다. 테스트는 메모리 저장 함수를 주입한다.
5. ViewportControls는 제목 없는 라운드 패널을 유지한다. 위에는 모드 선택 W/E/R 버튼, 아래에는 `Move [값] Rot [값] Scale [값]`을 가로로 표시한다. 체크박스는 제거한다. 좁은 뷰포트에서는 스냅 그룹을 줄바꿈해 입력칸 접근을 유지한다.
6. EditorApp의 `inspectorSource`는 assets 또는 scene 선택 출처를 기록한다. Inspector 포커스는 이를 바꾸지 않는다. Scene/Hierarchy에서 선택한 인스턴스와 Prefab 편집값은 서로 독립적으로 유지한다.
7. 기즈모 축 선은 원점에서 시작하고 중앙 원·사각형을 선 위에 그린다. 선택 Sprite 외곽선은 모든 객체 렌더링 이후, 기즈모 이전에 표시한다. Core SpriteRenderer의 outline은 이미지 조회·좌표 변환 함수를 받아 Core의 Editor 의존을 추가하지 않는다.

## 예상 결과

- 긍정: 각 스냅 설정이 모드와 앱 재시작 사이에 유지되고 회전값이 읽기 쉬워진다. 인스턴스 값 편집이 프리팹을 오염시키지 않으며 복수 Sprite의 렌더링 범위를 구분할 수 있다.
- 부정: 이전 무제한 회전값은 저장·로드에서 한 바퀴 이내 값으로 변환된다. 외곽선에는 이미지의 투명 여백도 포함된다. 아주 좁은 뷰포트에서는 도구 패널이 여러 줄을 차지한다.
- 중립: 스냅 설정은 에디터 사용자 상태이며 레벨·프리팹·테마 데이터에 저장하지 않는다. 픽셀 윤곽 추적·선택 효과의 Game View 표시·새 렌더링 컴포넌트 종류는 포함하지 않는다.
