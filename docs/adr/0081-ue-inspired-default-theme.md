# 0081. UE 에디터를 참고한 어두운 기본 테마

- 상태: 채택·구현
- 날짜: 2026-10-16
- 부분 대체: [ADR 0014](0014-love-theme-panels-and-status-hints.md)의 기본 팔레트. 패널 배치와 상태 힌트 결정은 유지한다.
- 관련: [ADR 0009](0009-editor-settings-and-themes.md), [ADR 0027](0027-windows-editor-packaging.md)

## 배경과 제약

사용자가 제공한 UE Blueprint 에디터 화면을 참고하여 기본 컬러 스킴 변경을 요청했다. 기존 색 역할과 설정 파일 계약을 유지하면서 중성 회색 바탕, 밝은 글자, 파란 선택 강조를 적용한다. 화면 구성이나 게임 콘텐츠의 색은 변경하지 않는다.

## 대안과 판단 기준

- 별도 선택 테마로 추가하면 기존 기본값은 유지되지만 요청한 기본 화면 변경을 충족하지 못한다.
- 내장 기본 팔레트를 교체하면 설정이 없는 실행과 기본값 복구에도 같은 화면을 제공한다. 별도 테마 파일과 내장 팔레트의 중복도 생기지 않는다.
- UE 화면의 색을 모든 요소에 그대로 적용하기보다 기존 색 역할에 대응시킨다. 실행·일시 정지·오류와 에셋 종류는 의미를 구별할 수 있는 색을 유지한다.

## 결정 및 근거

1. `Theme.DEFAULT_COLORS`에 해당하는 내장 팔레트를 어두운 중성 회색과 파란 강조로 교체한다. 전체 배경 `#141414`, 패널 `#1B1B1B`, 뷰포트 `#242424`, 표면 `#2B2B2B`, 입력 `#161616`으로 깊이를 구분한다.
2. 본문은 `#D0D0D0`, 선택 배경은 `#344F69`, 포커스와 선택 오브젝트는 `#008CFF`로 표시한다. 실행은 녹색, 일시 정지는 황색, 오류는 붉은색으로 구별한다.
3. `default`를 선택하거나 설정 파일이 없을 때 새 내장 팔레트를 사용한다. `atom-one-light`와 사용자 JSON 테마 선택 방식, 현재 사용자 설정은 유지한다. 배포물 옆에 이미 존재하는 사용자 설정은 패키징 시 덮어쓰지 않는다.
4. 실제 에디터 캡처를 통해 대비를 확인하고 사용자 가이드의 화면 이미지와 주석 이미지를 함께 갱신한다.

## 예상 결과

- 긍정: 기본 에디터에서 패널·입력·선택 상태가 일관된 어두운 색 계층으로 구별된다.
- 부정: 일부 색만 지정한 사용자 테마는 생략한 역할에 새로운 어두운 기본값을 상속한다. 기존 기본 테마 사용자는 색 변화에 적응해야 한다.
- 중립: 테마 파일 형식, 레이아웃, 프로젝트 데이터와 렌더링 콘텐츠는 바뀌지 않는다. 기존에 밝은 테마를 선택한 사용자는 `default`로 변경해야 새 팔레트를 사용한다.
