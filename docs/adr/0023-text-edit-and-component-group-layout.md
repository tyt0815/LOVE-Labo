# 0023. 공통 텍스트 편집 상태와 컴포넌트 그룹 경계

- 상태: 채택
- 후속 부분 대체: [ADR 0024](0024-collapsible-details-and-property-columns.md)의 Transform·클래스 접기 그룹과 이름/값 열
- 날짜: 2026-10-09
- 부분 대체: [ADR 0016](0016-ime-composition-and-field-confirmation.md)의 문자열 끝 입력·전체 선택 모델

## 배경과 제약

사용자는 Space 단축키 제거, 입력 위치를 보여주는 커서, 범위 선택 하이라이트, 선택 문자 대체 입력을 요청했다. 컴포넌트 그룹은 오브젝트 선언 프로퍼티보다 먼저 정렬하고 펼친 그룹의 범위도 명확해야 한다. Transform은 위에 유지하기로 사용자 확인을 받았다. 한글 조합·확인·포커스 이동과 기존 저장 계약을 유지한다.

## 대안과 판단 기준

- 입력칸마다 편집 로직을 구현하면 UTF-8 삭제·IME·클립보드·스크롤 처리가 서로 달라진다. 공통 TextEdit가 편집 계산을 맡고 각 입력칸이 transient 상태를 소유한다.
- 바이트 인덱스 커서는 한글을 잘못 잘라낼 수 있다. UTF-8 코드포인트 경계를 사용하고 실제 문자열 조작 시에만 바이트 위치로 변환한다.
- 조합 글자를 확정 문자열에 즉시 넣으면 갱신·확정 시 중복될 수 있다. 기존 IME 종료·늦은 OS 확정 입력 차단 규칙을 유지하며 조합을 선택 범위에 미리보기로 삽입한다.
- 그룹 제목만 있으면 본문 끝이 불분명하다. 헤더와 모든 펼친 항목을 같은 배경·테두리로 감싸고 내부 항목을 들여쓴다. Transform 자체 위치 변경은 사용자 선택대로 제외한다.

## 결정 및 근거

1. `editor/ui/text_edit.lua`가 문자열 삽입·삭제·커서/anchor 선택 범위·클립보드·마우스 위치 판정·가로 스크롤을 계산한다. 입력칸 소유자가 `editState`를 갖고 UI 렌더러·IME가 해당 상태를 사용한다. Core·authoring data에는 넣지 않는다.
2. 좌우/Home/End, Shift 선택, Ctrl+A/C/X/V, Ctrl+좌우/삭제, 마우스 클릭·드래그를 지원한다. 선택 입력은 선택 영역을 교체하고 Backspace/Delete는 앞/뒤 문자 또는 선택 범위만 지운다. 최초 Inspector·스냅 포커스의 전체 선택은 빠른 값 변경을 위해 유지하고 재클릭은 커서를 지정한다. 긴 입력은 커서가 보이도록 가로 스크롤한다.
3. 모든 입력칸(시작 화면·다이얼로그·Transform·클래스 프로퍼티·스냅)에 동일한 상태·그리기를 적용한다. Inspector/스냅은 기존 Root 포인터 캡처로 드래그 선택을 전달한다. 팝업과 시작 화면은 자체 마우스 이동·해제 이벤트로 선택을 종료한다.
4. IME 표시·확정 문자열은 현재 커서의 선택 범위에 삽입한다. 조합 갱신은 저장값을 바꾸지 않고 기존 접미 문자열을 보존한다. 커서 이동·클립보드 명령·같은 필드 재클릭은 조합을 끝낸 뒤 실행한다. Escape는 조합과 편집 상태를 비운다.
5. 테마 `textSelection`으로 선택 배경을 지정하고 커서·조합 밑줄은 기존 `focus`를 사용한다. 기존 사용자 테마에 새 역할이 없으면 기본값을 상속한다. 클리핑은 입력칸과 부모 스크롤 영역을 모두 유지한다.
6. ClassInspector는 컴포넌트 그룹을 먼저 정렬하고 오브젝트 선언 프로퍼티를 뒤에 표시한다. 그룹 배경은 헤더와 펼친 항목 높이를 합친 범위이며 항목 들여쓰기·안쪽 여백·그룹 간 간격을 적용한다. 접기·정렬은 override와 저장 스키마를 바꾸지 않는다.
7. Space 모드 전환과 힌트를 제거한다. 모드 선택은 W/E/R로 유지하고 편집 중 Space는 일반 문자 입력이다.

## 예상 결과

- 긍정: 모든 입력칸에서 한글을 포함한 중간 편집과 범위 교체가 일관되며 컴포넌트 프로퍼티 범위가 명확하다.
- 부정: 기존 같은 필드 클릭은 조합을 유지했지만 이제 조합 확정 후 커서를 옮긴다. Unicode 결합 문자·이모지의 grapheme cluster 단위 이동, 여러 줄 편집, Undo/Redo는 제공하지 않는다.
- 중립: 파일 형식·컴포넌트 상속·Core lifecycle과 runtime Transform은 변경하지 않는다. 텍스트 선택과 펼침 상태는 Editor transient 상태다.
