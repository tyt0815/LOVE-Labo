# 0044. CLI를 계층 편집·에셋 관리·코드 수정·검증으로 확장한다

- 상태: 채택·구현
- 날짜: 2026-10-10
- 확장: [ADR 0028](0028-agent-cli-and-standalone-game-export.md), [ADR 0042](0042-hierarchy-prefab-definitions.md)

## 배경과 제약

AI가 기본 생성·단일 값 수정만으로 작업하면 에셋 이동, 계층 복제·삭제, 중첩 Prefab 편집과 코드 검증에서 직접 저장 형식을 조작해야 한다. 사용자는 생각할 수 있는 실용적인 편집 작업을 CLI로 제공하도록 요청했다. GUI 없이 실행하고 기존 ID·상속·참조·revision·프로젝트 잠금을 유지해야 한다.

## 대안과 판단 기준

- JSON 파일을 개별 명령에서 직접 수정하면 Inspector와 기본값·상속 의미가 달라진다.
- EditorApp을 실행하여 GUI 이벤트를 흉내 내면 헤드리스 CLI의 목적과 충돌한다.
- 공용 Project·Level·PrefabEditor·WorldLoader를 호출하면 데이터 계약을 재사용하며 GUI 의존성을 만들지 않는다.

## 결정 및 근거

1. CLI는 프로젝트 검증, 클래스 조회·소스 교체, 폴더 생성, 에셋 목록·정보·복사·가져오기·이동·이름 변경·삭제, 레벨 부모·값 초기화·검증, 인스턴스 목록·이름·다중 복제·삭제·재부모화·초기화, Prefab 노드 조회·값·참조·부모·자손 추가·이름 변경·제거를 제공한다.
2. `Cli`는 파싱·잠금·레벨 작업을 소유한다. `CliAssets`는 파일·클래스·프로젝트 진단, `CliPrefab`은 Prefab 문서 작업을 소유한다. Prefab 조작은 Inspector와 같은 `PrefabEditor`를 사용한다.
3. Prefab 노드는 `root/<child-id>/...` 경로로 지정하며 내부 object 참조도 이 경로를 입력할 수 있다. 응답은 노드 경로·가상 ID 목록과 프로퍼티 스키마·유효 값·문서 데이터를 제공한다. 읽은 문서의 SHA-256 revision을 변경 요청에 선택적으로 첨부한다.
4. `instances`는 JSON 배열 또는 쉼표로 구분한 CLI 숫자 목록이다. 다중 작업은 하나의 레벨 문서에서 검증한 뒤 한 번 저장한다. 잘못된 참조·값·순환·revision은 저장을 거절한다. 기본 LObject도 원본 에셋 없이 추가한다.
5. 클래스 소스 교체는 메모리 프로젝트 어댑터로 Lua 클래스 로딩·상속·스키마를 검증한 뒤 원본 바이트와 비교하여 저장한다. 게임 동작의 정확성을 보장하지는 않는다. 프로젝트 검증은 오류를 에셋별로 수집하며 `beginPlay`·프레임 update를 실행하지 않는다.
6. 에셋 파일 복사는 새 ID를 발급하고 나머지 메타데이터를 유지한다. 가져오기·복사는 기존 파일·메타데이터를 덮어쓰지 않는다. 이동·이름 변경은 기존 ID를 유지하며 파일 관리의 경계·기본 레벨 보호를 기존 Project API에 위임한다.
7. GUI 문서와 자동 동기화하거나 GUI Undo 기록에 CLI 작업을 추가하지 않는다. `asset.delete`는 Project의 실제 삭제이며 CLI에 영구 Undo 저장소를 추가하지 않는다. API가 제공하는 rollback·검증 범위를 넘어 운영체제 I/O 실패 전체에 대한 트랜잭션을 주장하지 않는다.

```text
Cli --의존--> CliAssets --의존--> Project / LuaClass
Cli --의존--> CliPrefab --의존--> PrefabEditor
Cli --의존--> Level / WorldLoader
```

상속 관계를 추가하지 않는다. 파일 작업과 Prefab 문서 작업을 분리하고 값·계층 계약은 기존 공용 모델에 둔다.

## 예상 결과

- 긍정: AI가 스키마와 계층을 조회한 뒤 동일한 API로 편집·검증·Export를 이어갈 수 있다. 직접 JSON 편집이 줄어든다.
- 부정: 명령 계약과 인자의 문서·호환성을 유지해야 한다. GUI와 CLI 동시 수정은 계속 지원하지 않는다.
- 중립: 화면 선택·기즈모·팝업·Play UI를 제어하지 않는다. 게임 코드는 프로젝트 Lua이고 컴포넌트 구성도 코드의 책임이다.
