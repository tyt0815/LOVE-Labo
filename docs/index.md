# LÖVE Labo 사용자 가이드

LÖVE Labo는 Lua로 게임 동작을 작성하고 에디터로 클래스·Prefab·레벨을 구성하는 2D 제작 도구입니다. AI 에이전트도 CLI로 같은 프로젝트를 만들고 수정·검증할 수 있습니다.

이 가이드는 저장소의 현재 구현을 기준으로 합니다. 실행 환경은 **LÖVE 11.5 + LuaJIT/Lua 5.1**, 문서는 개발 중인 버전입니다. 아직 배포되지 않은 변경은 공개 사이트에 반영되기 전 로컬 문서에서 먼저 확인할 수 있습니다.

![에디터의 주요 영역](guide/images/editor-overview.svg)

- 처음 사용한다면 [첫 프로젝트와 실행](guide/getting-started.md)을 따라 하세요.
- 화면 조작은 [에디터 화면과 선택](guide/editor.md)에 정리했습니다.
- 게임 코드는 [Lua API](guide/lua-api.md), 자동화는 [AI 시작 페이지](guide/ai.md)와 [CLI 명령](cli-and-export.md)을 참고하세요.
- 기존 컴포넌트·Prefab의 상세 예제와 개발 설계 문서도 같은 사이트에서 읽을 수 있습니다.

위 이미지의 번호는 **1 계층, 2 뷰포트, 3 Inspector, 4 에셋 브라우저**입니다. 모든 화면 이미지는 실제 에디터에서 생성한 예제 프로젝트를 캡처했습니다.
