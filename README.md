# LOVE Labo

LÖVE 11.5 + LuaJIT을 사용하는 2D 제작 에디터다. 현재 외부 프로젝트 생성·탐색은 Windows에서 지원한다.

## 실행

```powershell
love .
love . --test
```

시작하면 프로젝트 런처가 표시된다.

- **New project**: 프로젝트 이름과 부모 폴더를 지정한 뒤 **Create project**를 누른다. 부모 폴더 아래에 새 프로젝트 폴더를 만들며 기존 폴더는 덮어쓰지 않는다.
- **Open project**: `project.labo`가 있는 프로젝트 폴더를 지정하고 **Open project**를 누른다. 프로젝트 폴더를 런처로 드래그해서 경로를 입력할 수도 있다.
- **Browse**: 내장 폴더 선택기를 연다. 폴더를 클릭해서 들어가고 **Up**으로 부모로 이동한 뒤 **Use this folder**로 선택한다. 경로 입력 및 `Ctrl+V` 붙여넣기도 가능하다.

```text
MyProject/
  project.labo
  Assets/
```

프로젝트가 열리면 좌측 계층, 중앙 뷰포트, 우측 인스펙터와 하단 에셋 브라우저가 표시된다. 에셋 브라우저는 `Assets/`만 보여준다.

- 왼쪽 폴더 트리에서 `+`/`-`로 펼치거나 접고, 이름을 클릭해서 해당 폴더를 연다.
- 오른쪽 목록의 폴더는 더블클릭 또는 선택 후 `Enter`로 연다. `Up` 또는 `Backspace`로 상위 폴더에 돌아간다.
- **Refresh** 또는 브라우저에 포커스가 있을 때 `Ctrl+R`로 외부에서 추가·삭제한 파일을 반영한다. 트리와 목록은 각각 마우스 휠로 스크롤한다.
- 브라우저 위쪽 경계선을 드래그하면 높이를 조절한다. 헤더의 `-`/`+` 버튼으로 접거나 펼친다.

이번 단계는 파일·폴더 탐색까지다. 에셋 선택은 인스펙터를 변경하지 않는다. 프로젝트를 열면 빈 메모리 Level로 시작하며, 현재 레벨 선택·자동 로딩은 아직 연결하지 않았다.
