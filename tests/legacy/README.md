# 이전 데이터 계약의 테스트 원본

이 폴더는 LObject 클래스 상속·컴포넌트 계층·Sources 루트를 사용하던 테스트 원본을 보존한다. 파일을 덮어쓰지 않고 `.lua.txt`로 보관하여 이전 계약과 마이그레이션 검토에 활용한다.

현재 실행 대상은 tests/Runner.lua에 명시한다. attachedWorkflow와 scriptRuntime은 새 부착 스크립트 계약을 검증하고, UI·텍스트 입력·기즈모·오브젝트 계층 테스트는 새 모델에 맞춰 계속 실행한다. 이전 테스트 348개 통과 기록과 현재 테스트 개수는 서로 다른 데이터 계약이므로 직접 비교하지 않는다.
